# Multipl Spend Analysis Calculator

AI-powered spend analysis calculator that helps users understand their spending patterns and discover potential savings with Multipl.

## Features

- Personalized spend analysis based on demographics (age, income, gender, marital status)
- Smart brand recommendations with realistic spend allocations
- Interactive spend table with editable amounts
- Savings calculation showing potential benefits with Multipl

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn-ui
- Framer Motion

## Development

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

Deployed on Vercel with automatic deployments from the main branch.
